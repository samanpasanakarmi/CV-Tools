# CV Studio user guide

This guide describes the current authenticated core application, not the historical browser-only prototype.

1. Open the locally running application or the team-approved deployed URL. Register using email/password, verify email if required and log in. Use **Forgot your password?** if needed.
2. Open **My Profile**. Enter your reusable contact details and professional summary, then add work experience, education, projects, skills, languages and certificates. Use exact work dates and mark ongoing work as Present. Optional JPEG/PNG/WebP photo is resized locally.
3. Changes automatically save after about 1.5 seconds without edits. Wait for the saved indicator; **Save now** forces a save. A failed/blocked save is not persisted. Correct invalid information or reconnect and retry.
4. Open **My CVs → New CV**. Enter title, company and position. Select relevant profile entries, CV-specific headline/summary, contact visibility, template and accent color. The two photo templates allow optional picture display.
5. Add custom fields with a heading and multiline details (e.g. Awards, Volunteering or Driving licence). Incomplete fields are hidden in the CV. Each CV has its own custom fields.
6. Under **CV section order**, use up/down or Reset order. The two-column layout orders its sidebar and main column separately. Preview updates immediately.
7. Use **Save PDF**, choose Save as PDF in the browser print dialog, select A4 and disable browser headers/footers if necessary. Check all pages. TXT and JSON exports are also available.
8. In **My CVs**, duplicate a CV to reuse settings or delete a CV you no longer need. Changes to the shared master profile affect existing CVs; CV-specific selections and custom fields are independent.
9. In **Account**, change password, download full backup JSON or erase profile and CVs. Erasure is permanent and does not delete the Auth login. Backup restoration is not implemented. Store backups privately.
10. Sign out after use, especially on a shared computer. Refresh requires login; unsaved edits may be lost if leaving before a successful cloud save.

Until release gates are met, use disposable test accounts and fictional CV information. AI is not available in the core release.
