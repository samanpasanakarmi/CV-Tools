# Customer meeting guide — Aino Haavisto (Metropolia)

## 30-minute agenda (send to customer in advance)
1. **2 min** — Introductions and desired outcome.
2. **6 min** — What problem is the tool solving? Who are its real users?
3. **12 min** — Confirm must-have fields, workflow, PDF, exports and privacy.
4. **6 min** — Show user journey / proposed prototype and seek feedback.
5. **4 min** — Summarize decisions, uncertainties, next steps and arrange next meeting.

## Questions — do not assume the answers
1. Who will use it: students, employees, job seekers, career advisers?
2. Is web or offline preferred? Does the tool need to work with no internet?
3. Must user data persist across different devices or only on one computer?
4. Would accounts/login and a backend be necessary for first version?
5. Which fields are essential (jobs, degree, languages, links, referees, achievements)?
6. Should users maintain multiple tailored CVs as separate named versions?
7. How many visual templates and languages would be useful?
8. Should PDF be generated by one click directly, or is browser Print to PDF acceptable?
9. Besides PDF, which formats should be supported: TXT, JSON, DOCX, others?
10. What privacy, retention, accessibility or organizational requirements apply?
11. Can we use anonymized sample data for demos? What would make the project successful?
12. How will you evaluate/accept the final software and receive it?
